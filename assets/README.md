# LangParse brand assets

The LangParse mark is a data viewport: four precise corner brackets focus on a
small structured grid, where one champagne-gold cell represents an identified
result.
The open geometry communicates lightweight document parsing, while the grid
retains the project's deeper Excel structure focus.

## Files

- `langparse-mark.svg`: primary scalable source with a transparent background.
- `langparse-mark-512.png`: high-resolution raster export for package pages and
  repository artwork.
- `langparse-mark-128.png`: compact raster export for avatars and small surfaces.

## Colors

- Charcoal: `#1B1B1D`
- Champagne gold: `#C5A46D`

Keep the background transparent and preserve the open space between the frame
and the data cells. Do not add an Excel-style letter mark, document silhouette,
gradient, or shadow. At small sizes, use the mark without text.
