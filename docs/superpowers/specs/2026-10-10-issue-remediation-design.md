## 设计约束

- 公式仅解析引用，不计算，不访问外部文件；动态/不支持的引用必须诊断，禁止猜测。
- 图表/图片语义以已提取对象事实为源，不默认 OCR/VLM；对象覆盖与单元格覆盖分开。
- Bundle 带 schema version、facts/structures/relations/diagnostics/provenance 分区，省略二进制，查询无需遍历内部 dataclass。
- 分块策略必须保留完整文本、可预测窗口边界和来源 metadata，非法预算立即报错。
- GitHub 内容仅更新有实证的状态，不把本地未推送代码写成远端已交付。

## 验证

每个切片先补能复现缺口的行为测试，再运行对应模块回归。格式/文档不写镜像测试。最终检查全仓 Ruff、相关组合回归、零依赖导入及构建安装。私有样本缺失时记录待补证据，不修改已有真值或放宽门槛。
